Backtest: would it have seen it coming?

For each public FDA action, the detector is replayed weekly for the 12 weeks before it, on only the reports FDA had received by each date. A flag counts only if it is on one of the three event months before that date, so a spike from an earlier issue is not credited to a later one.

Public reports reach FDA up to 30 days after the manufacturer hears of an event, and recent months fill in slowly. A manufacturer's own complaint feed sees the same reports weeks earlier, which is where this detector belongs. A flag shows that a complaint type rose, not what caused it, and lead time is measured against the public start date of each action. False alarms are not measured here: the replay scans only each action's own mode (see the flag history below).

How it works

  1. Count. Each failure mode is a list of phrases (the manufacturer's allegation wording and consumers' own words). openFDA counts every matching report by event month, server-side.
  2. Detect. A mode is flagged when its share of reports is at least 1.5x its previous six months, with at least 30 reports and a Poisson p below 0.001. Months wait until half their usual reports have arrived.
  3. Tag. Claude reads narratives the phrases cannot place and picks a mode with a quote as evidence. Guardrails: the mode must exist, the quote must be in the text, low confidence goes to a person, and when the manufacturer's allegation sentence names a known mode, that mode wins.
  4. Gate. The tagger only ships if it passes the eval gate in CI.

Limits: openFDA narratives are blank for many of the latest reports, which can hide a rise but not create one. Report counts are not failure rates. This page reads public data only and says nothing about causes.

Run it yourself

Python 3.10 or later. From the repo folder:

pip install -e ".[claude]"
csd snapshot && csd detect && csd backtest
golive run eval/golive.yml --agent agent:rules_agent
