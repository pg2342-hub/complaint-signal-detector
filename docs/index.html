How it works

  1. Count. Each failure mode is a list of phrases (the manufacturer's allegation wording and consumers' own words). openFDA counts every matching report by event month, server-side.
  2. Detect. A mode is flagged when its share of reports is at least 1.5x its previous six months, with at least 30 reports and a Poisson p below 0.001. Months wait until half their usual reports have arrived.
  3. Tag. Claude reads narratives the phrases cannot place and picks a mode with a quote as evidence. Guardrails: the mode must exist, the quote must be in the text, low confidence goes to a person, and when the manufacturer's allegation sentence names a known mode, that mode wins.
  4. Gate. The tagger only ships if it passes the eval gate in CI.

Limits: openFDA narratives are blank for many of the latest reports, which can hide a rise but not create one. Report counts are not failure rates. This page reads public data only and says nothing about causes.
